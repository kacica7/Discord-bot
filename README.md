# Discord-bot
Discord bot that takes user avatar and randomizes a coding meme.
It features 3 commands:

!hello - it greets the user with a simple Hello!
!avatar - gets the user's avatar 
!meme @someone - generates a random coding meme from the folder and puts the user's avatar on it. The issue here is that I didn't have enough time to make this bot perfect, so the avatar image isn't really placed correctly.


#installation
run pip install > requirments.txt

#running the code
python3 bot_code.py
